# UI and Runtime Evidence

Launch the actual application/site/build on representative targets. Traverse primary journeys with realistic state and inspect key visual outputs plus console/crash logs.

When relevant, cover responsive sizes, touch/keyboard/controller/pointer, history/back/deep links, interruption/resume, loading/empty/error/stale/permission/degraded states, focus order, semantics, contrast, screen reader, text scaling and reduced motion. Measure interaction responsiveness or frame pacing when experience quality depends on it.

Source/component inspection cannot pass a runtime/visual gate. Repeat a minimal critical set against the actual production target after deployment.
