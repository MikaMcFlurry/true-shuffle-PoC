# Risk-Lens Catalog

Choose relevant distinct lenses; do not mechanically run every item.

- Product/UX/accessibility: first value, dead ends, status/trust cues, destructive actions, degraded states, navigation, device/input/accessibility failures.
- Correctness/state: boundaries, stale/partial data, retry/idempotency, concurrency, time/locale, cache sync, restart/reconnect, mixed versions.
- Security/privacy: authz/object access, escalation, unsafe input/files, secrets/tokens, exposure/logging, account/session recovery, untrusted content/prompts/tools.
- Performance/reliability: worst-case latency, resources, large data/assets, dependency outage, retry storms, durable work, frame pacing/input latency.
- Data/migration: partial migration, deploy order, truncation/corruption, invariants, restore viability, duplicate side effects.
- Operations/release: environment drift, secret wiring, health/observability, failed post-deploy journey, flags/canary, rollback reality, alert diagnosability.
- AI: malformed/hallucinated outputs, injection, unsafe tools, provider failure, privacy, eval gaps, cost/latency/fallback inconsistency.
- Games: save/progression loss, physics/frame dependence, collision/camera, authority/desync/reconnect, economy exploits, device/remapping and asset streaming.
