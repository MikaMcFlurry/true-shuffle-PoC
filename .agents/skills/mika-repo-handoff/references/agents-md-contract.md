# Agent Entrypoint Contract

The agent entrypoint is a concise map, not project history. Prefer root `AGENTS.md` for ordinary repositories only when compatible with existing scopes. Governed repositories may use another canonical or approved path.

Include or link:

1. project identity and purpose;
2. exact read order and Handoff Map path;
3. canonical setup/run/build/static/test/runtime commands;
4. baseline and environment pointers;
5. authority/conflict rules;
6. critical architecture/data/security boundaries;
7. deployment/recovery/operations pointers;
8. quality and completion gates;
9. documentation freshness obligations.

Verify commands from executable configuration or direct execution; never invent them. Explain precedence of root, nested, and tool-specific instructions. Do not embed full histories, feature matrices, benchmark catalogs, or test logs.

For an entrypoint created or amended by this Skill, prefer no more than 220 lines. A longer linked canonical file is not automatically invalid, but the handoff should add a compact approved start pointer when possible.
